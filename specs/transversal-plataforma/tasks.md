# Tareas — Calidad de la plataforma y operación

> Tareas atómicas ordenadas por riesgo y luego **de adentro hacia afuera**: comprobaciones previas y puertas baratas → Dominio → Aplicación → Infraestructura → Api → scripts y pruebas de integración. Cada tarea cabe en un commit, empieza con una prueba que falla (o con la comprobación definida) y deja el proyecto compilando. Cada criterio de aceptación de la spec debe aparecer en al menos una tarea. Los puertos base (`IReloj`, `IUnidadDeTrabajo`, `IControlDeLimites`) son de `transversal-seguridad`; el correo con cuota y cola, de `identidad-seguridad` (T30).

Formato de cada línea: `- [ ] T01 [Capa] Descripción (cubre: AC-XXX-01, XXX-01)`.
