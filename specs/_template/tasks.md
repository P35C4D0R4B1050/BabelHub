# Tareas — Título de la feature

> Tareas atómicas ordenadas **de adentro hacia afuera**: Dominio → Aplicación → Infraestructura → Api → Web → pruebas de integración y E2E. Cada tarea cabe en un commit, empieza con una prueba que falla y deja el proyecto compilando. Cada criterio de aceptación de la spec debe aparecer en al menos una tarea.

Formato de cada línea: `- [ ] T01 [Capa] Descripción (cubre: AC-XXX-01, XXX-01)`.

- [ ] T01 [Dominio] Descripción de la tarea (cubre: AC-XXX-01, XXX-01)
