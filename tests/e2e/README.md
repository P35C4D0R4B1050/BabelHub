# Pruebas E2E (Playwright)

Recorridos completos sobre `BabelHub.Web` que verifican los criterios de aceptación de las specs: búsqueda → compra con recojo → cambio de estado, compra digital → descarga, traslado, ajuste de inventario, etc. Se crean con `ui-screen` y `spec-implement` cuando la Web tenga las pantallas.

Convenciones: un archivo por recorrido, el criterio en el nombre o en una anotación (`AC-XXX-NN`), datos de ejemplo de `docs/07-proceso-de-desarrollo/02-convenciones-tecnicas.md` y ejecución contra el entorno local de `infra/`.
